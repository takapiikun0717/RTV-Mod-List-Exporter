# RTV-Mod-List-Exporter
modsフォルダに入っているmodの総数、有効、無効になっているMod名・バージョン・優先度をリスト化します。
Modリストは（"C:\Users\アドレス\AppData\Roaming\Road to Vostok\mod_list.txt"）、（"C:\Program Files (x86)\Steam\steamapps\common\Road to Vostok\mod_list.txt"）の二か所に入っています。
デフォルトでは、F8キーでゲーム内からいつでもModリストを再生成できます。
MCMの設定から、キー設定を変更できます。

導入方法
modsフォルダにModListExporter.vmzファイルを入れゲームを起動、自動的に生成されます。

前提Mod
Metro Mod Loder
ModConfigurationMenu
